# Mamun Hossain — Personal Portfolio

A focused, responsive one-page portfolio for Mamun Hossain, a backend-focused full-stack developer building event-driven, production-grade systems.

## Stack

- Next.js 15 with the App Router
- React 19
- Tailwind CSS 4 via PostCSS
- Lucide React icons
- Lightweight CSS motion with `IntersectionObserver`

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production checks

```bash
npm run lint
npm run build
```

The public site is intentionally static and content-led. It does not use the previous Firebase CMS, authentication flow, dashboard, blog, or multi-page project routes. Portfolio content lives in the page components so it can be reviewed and updated directly.
